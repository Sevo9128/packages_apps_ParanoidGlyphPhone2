# Glyph manager for Nothing Phone 2 (Pong)
##### Lineage 23.X branch - Required for build

## Setup

Clone the correct branch into **packages/apps/ParanoidGlyphPhone2**

You can do so by selecting the branch corresponding to your rom at the top and executing this command:
> git clone https://github.com/Sevo9128/packages_apps_ParanoidGlyphPhone2.git -b lineage-23.X packages/apps/ParanoidGlyphPhone2
